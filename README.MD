**Contal Master** é um projeto de jogo Academico  desenvolvido no **Godot Engine 4**, focado no aprendizado prático e no desenvolvimento de mecânicas dinâmicas de forma colaborativa em Revisões de Auditoria em Contabilidade.

---

## 📌 Sobre o Projeto

Este repositório contém o código-fonte, cenas e assets visuais/sonoros do jogo **Contal Master**. O fluxo de trabalho é organizado em equipe utilizando Git e GitHub para o versionamento.

---

## 🛠️ Tecnologias Utilizadas

- **Engine:** Godot Engine 4.x
- **Linguagem:** GDScript
- **Controle de Versão:** Git / GitHub (Feature Branch Workflow)

---
