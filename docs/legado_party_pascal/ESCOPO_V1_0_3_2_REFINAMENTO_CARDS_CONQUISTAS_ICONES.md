# V1.0.3.2 — Refinamento dos cards de conquistas e ícones por desafio

## Objetivo

Refinar a área de Conquistas para manter os desafios visíveis ao jogador, ocultando apenas os títulos das conquistas bloqueadas e adicionando ícones próprios por desafio.

## Alterações

- Conquistas bloqueadas passam a mostrar o título genérico `Bloqueado`.
- O requisito/subtítulo das conquistas bloqueadas continua visível como guia de desbloqueio.
- Conquistas desbloqueadas continuam mostrando o título real e a descrição.
- Foram adicionados 15 ícones PNG próprios, um para cada conquista.
- Os cards desbloqueados usam os ícones temáticos coloridos.
- Os cards bloqueados continuam usando o cadeado e visual cinza.
- A notificação de conquista também passa a usar o ícone próprio quando disponível.
- As insígnias Bronze, Prata, Ouro e Platina permanecem como área superior de progresso.

## Critérios de aprovação

- Títulos reais não aparecem em conquistas bloqueadas.
- Requisitos das conquistas bloqueadas aparecem normalmente.
- Cada conquista desbloqueada tem ícone temático próprio.
- Cards bloqueados permanecem com cadeado.
- Layout responsivo 3/2/1 continua preservado.
