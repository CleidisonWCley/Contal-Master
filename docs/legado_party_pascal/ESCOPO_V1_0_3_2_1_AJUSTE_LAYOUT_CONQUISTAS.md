# V1.0.3.2.1 — Ajuste de layout da tela de Conquistas

## Objetivo
Dar mais respiro para a parte inferior da tela de Conquistas, garantindo que o botão Voltar fique confortável e visível em 1280x720.

## Ajustes
- Compactação leve do cabeçalho de conquistas.
- Redução moderada da insígnia no topo para liberar espaço vertical.
- Botão Voltar movido para um container próprio com margem inferior segura.
- Margem inferior da área segura aumentada.
- Grade 3/2/1 de conquistas preservada.

## Fora do escopo
- Lógica de desbloqueio.
- Ícones das conquistas.
- Insígnias.
- Progresso e salvamento local.
